# RUNTIME-PROTOCOL — клетка роя cell-swarm

> Исполнимая модель динамики узла: уравнение ρ̇, фазовая машина GENESIS_EXEC,
> волатильный мета-слой, рак-фильтр. stdlib-only, офлайн.

## Что это

Клетка реализует формальную модель из сессии «Железо · Стек · Рантайм»
(спецификация: `rtynbirf/nous`, ветка `agents/execution`, `docs/genesis/runtime-protocol.md`):

```
ρ̇ = MΛ·[α(1−ρ)ρc² + ρ²] − (1−κMΛ)·βρ − Ωₐ·pΘ·(ρc−ρ),  при ρ > 0
```

- генератор смысла `MΛ[α(1−ρ)ρc² + ρ²]`
- демпфер долга `(1−κMΛ)·βρ` — выкачка Картеля
- каратель `Ωₐ·pΘ·(ρc−ρ)` — действует только ниже критической массы; при ρ ≥ ρc обращается в ноль

Фазовая машина: `SUBCRITICAL → FORAGING → COHERENCE → OVERCLOCK → TRANSITION → POST_GENESIS`.

## Быстрый старт (закон 5 «Семя», офлайн)

```bash
make demo      # демо-прогон: дойный режим → 3 действия → такт 13 → терминальный дамп
make demo-map  # демо контура сверки: два режима сверки + рой без центральной карты
make verify    # 17 живых приёмок (unittest: 7 ядра + 10 контура)
```

Зависимости: Python 3.10+ (stdlib only). Ничего скачивать не нужно.

## Живая карта: контур сверки (`reconciliation.py`)

Протокольные действия в `run_protocol` срабатывают по расписанию — открытый
контур, угадчик по построению. `reconciliation.py` замыкает его:

```
ЖЕЛАЕМОЕ (Spec: ρ*, ε) ← сверка → НАБЛЮДАЕМОЕ (замер ρ) → ДЕЙСТВИЕ (актюатор)
```

- **Карта — глагол:** ошибка пересчитывается каждый такт и нигде не хранится.
- **Два слоя допуска:** ε спеки (error budget, бурсты шоков допустимы при
  ≥80% удержания — практика SRE) и deadband (порог подбива). Стационарного
  удержания не существует: равновесие в модели — репеллер (проверено
  аналитически, ADR-0002); существует баттинг в бюджете.
- **Сверка идемпотентна и level-triggered:** действие — функция текущей ошибки, не её изменения; реплей того же состояния даёт бит-в-бит тот же факт (ADR-0003, канон операторов).
- **Геном слушает события, не часы:** push→main сообщает ядру cell-swarm — пин клетки догоняется живым ls-remote по факту события (не по времени и не по накоплению, TH-RTP-04).
- **Актюатор знаний:** клетка знает своё уравнение — масса M вычисляется
  аналитически под заданную скорость подхода к цели при текущем ρ,
  потолок M=1.0 ниже 1/κ ≈ 1.053 (переворот долга невозможен по построению);
  α — трим, β — руль территории, не клетки.
- **Территория течёт:** долг ползёт, шоки среды бьют независимо от воли клетки.
- **Адаптивная сверка:** ошибка вне бюджета — такт учащается; в бюджете —
  замедляется.
- **Рой без центральной карты:** клетки обмениваются наблюдениями (gossip) и
  сдвигают свои цели; сходимость — эмерджентная (`reconcile_swarm`).

Демо (`make demo-map`) показывает два режима: сверка быстрее изменения
(удержание: 100% хвоста в допуске) и сверка медленнее изменения (карта
отстаёт — допуск нарушается). Детали и альтернативы — `docs/adr/0002`.

## Границы (честно)

- Метрики α, β, ρ, MΛ — **модельные, безразмерные**; на реальные данные не
  операционализированы (это отдельный тикет, не эта клетка).
- Интегратор — явный Эйлер, демо-масштаб.
- Откат после генезиса не реализован намеренно: `VOLATILE_META` удаляет
  объясняющие модели; `method_memory=False` необратим по построению.

## Метаболизм

| Команда | Что делает |

| `make verify` | тесты: уравнение, фазовая машина, рак-фильтр + контур сверки |

| `make demo-map` | демо контура сверки: два режима + эмерджентный рой |
