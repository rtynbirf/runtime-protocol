# RUNTIME-PROTOCOL — клетка роя cell-swarm

> Исполнимая модель динамики узла: уравнение ρ̇, фазовая машина GENESIS_EXEC,
> волатильный мета-слой, рак-фильтр. stdlib-only, офлайн.

## Что это

Клетка реализует формальную модель из сессии «Железо · Стек · Рантайм»
(спецификация: `rtynbirf/nous`, ветка `agents/execution`, `docs/genesis/runtime-protocol.md`):

```
ρ̇ = MΛ·[α(1−ρ)ρc² + ρ²] − (1−κMΛ)·βρ − Ωₐ·pΘ·(ρc−ρ),  при ρ > 0
```

- генератор смысла `MΛ[α(1−ρ)ρc² + ρ²]`
- демпфер долга `(1−κMΛ)·βρ` — выкачка Картеля
- каратель `Ωₐ·pΘ·(ρc−ρ)` — действует только ниже критической массы; при ρ ≥ ρc обращается в ноль

Фазовая машина: `SUBCRITICAL → FORAGING → COHERENCE → OVERCLOCK → TRANSITION → POST_GENESIS`.

## Быстрый старт (закон 5 «Семя», офлайн)

```bash
make demo     # демо-прогон: дойный режим → 3 действия → такт 13 → терминальный дамп
make verify   # 7 живых приёмок (unittest)
```

Зависимости: Python 3.10+ (stdlib only). Ничего скачивать не нужно.

## Границы (честно)

- Метрики α, β, ρ, MΛ — **модельные, безразмерные**; на реальные данные не
  операционализированы (это отдельный тикет, не эта клетка).
- Интегратор — явный Эйлер, демо-масштаб.
- Откат после генезиса не реализован намеренно: `VOLATILE_META` удаляет
  объясняющие модели; `method_memory=False` необратим по построению.

## Метаболизм

| Команда | Что делает |
|---|---|
| `make verify` | тесты уравнения, фазовой машины, рак-фильтра |
| `make demo` | прогон протокола с терминальным дампом и вердиктами рак-фильтра |
