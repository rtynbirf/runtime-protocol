# ADR-0005: Rust-тропа — протокол крови доказывается вторым языком

- Статус: принято
- Дата: 2026-11-08
- Контекст: кровь клетки (ADR-0004) живёт в Python (`blood.py`). Волна вторая
  владельца («рой из модели в кровь… Rust-тропа») требует тропу в Rust.

## Проблема

Протокол, реализованный ровно одним языком, — это свойство языка, а не
протокола. Пока канон крови умеет только Python, «клетку можно родить где
угодно» остаётся обещанием. Нужен второй язык — но тропа, а не второй
международный проект: копить дубликаты логики — плодить расхождения.

## Решение

1. **Тропа, не шоссе.** `rust_trail/` — std-only (крейтов нет, сети нет),
   три функции: канонический JSON (сортировка ключей, компактные разделители,
   экранирование как `json.dumps(..., ensure_ascii=False)`; без float — канон
   крови не содержит плавающих), чистая sha256, `envelope_hash` (ADR-0004).
2. **Золотые пробы — мост.** `tools/make_golden.py` генерирует из Python-ядра
   канонические байты тел конвертов и их хеши → `rust_trail/tests/golden/`.
   `golden_match.rs` строит те же тела в Rust и сверяет байт-в-байт. Источник
   истины один — ядро; Rust не «свою правду пишет», а повторяет байты ядра.
3. **Храповик проб.** CI (`rust-trail.yml`): `make_golden.py --check` — если
   байты ядра ушли от закоммиченных проб, проба красная и оба языка двигаются
   вместе, осознанно.
4. **Честные границы.** Чего тропа НЕ делает: парсинг произвольного JSON,
   верификацию хеш-цепи летописи, транспорт. Это шоссе — отдельные решения.

## Следствия

- Протокол крови доказан как протокол: второй язык повторил байты ядра.
- Новая клетка роя может родиться в Rust, не спрашивая разрешения у Python.
- Изменение канона = одновременная правка ядра и тропы + новые пробы —
  расхождение языков ловится CI, а не кровью.
