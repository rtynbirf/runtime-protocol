# ADR-0002: Контур сверки «живая карта» (reconciliation.py)

- Статус: принято
- Дата: 2026-11-07
- Контекст: TH-RTP-01 дал клетку с открытым контуром (действия по расписанию).
  Эта запись замыкает контур. (Ворклог TH-RTP-02 — в H-PE11-PHOENIX.)

## Проблема

`run_protocol` в `runtime_protocol.py` запускает протокольные действия
по часам (`t_revoke=5, t_coherence=10, t_overclock=15`) — открытый контур:
клетка действует вслепую, не глядя на фактическое состояние. Это угадчик
по построению: расписание — карта, а территория (ρ(t)) течёт своя.

## Решение

`reconciliation.py` — замкнутый контур сверки (живая карта):

1. **ЖЕЛАЕМОЕ** (`Spec`: ρ*, ε) ← сравнение → **НАБЛЮДАЕМОЕ** (замер ρ)
   → **ДЕЙСТВИЕ** (актюатор). Ошибка пересчитывается каждый такт, нигде
   не хранится: карта — глагол.
2. **Два слоя допуска.** ε спеки — error budget (вердикт допускает бурсты
   шоков среды при ≥80% удержания — практика SRE); `deadband` — порог
   подбива внутри бюджета. Основание: равновесие модели при любом
   ρ* ∈ (0, ρc) неустойчиво-репеллерное (проверено аналитически: условие
   притяжения dρ̇/dρ<0 в точке ρ* недостижимо ни при каких α, β, M в
   допустимых окнах) — стационарного удержания не существует, существует
   баттинг в бюджете.
3. **Актюатор — модельно-предиктивный.** Клетка знает своё уравнение, и
   масса M при каждом подбиве вычисляется аналитически под заданную
   скорость подхода v_des при текущем ρ:

       M = (βρ + ΩₐpΘ(1−ρ) + v_des) / (α(1−ρ)ρ + ρ² + κβρ)

   Потолок M=1.0 ниже 1/κ ≈ 1.053 — член долга (1−κM)βρ не переворачивается
   в генератор по построению (при M > 1/κ runaway необратим: ρ² побеждает).
   α — двусторонний трим с ограничением скорости; β не трогается (валюта
   территории). Единственная память контроллера — I-канал с утечкой
   (подстройка остаточного смещения модели), не карта территории.
4. **Территория течёт** (`Territory`): долг ползёт вверх, шоки среды
   сбрасывают ρ независимо от воли клетки.
5. **Адаптивная частота сверки**: вне бюджета такт учащается (dt → dt_min),
   в бюджете — замедляется (dt → dt_max).
6. **Рой без центральной карты** (`reconcile_swarm`): каждая клетка ведёт
   свой контур по своей спеке; связь — gossip: клетка видит среднее соседей
   и сдвигает свою ЦЕЛЬ, не чужое тело. Сходимость роя плотнее изолированных
   клеток — эмерджентная, центрального контроллера нет.

## Рассмотренные альтернативы

- **Расписание с обратной связью по времени** (расширенный run_protocol) —
  отклонено: время — не состояние territory, угадчик остаётся угадчиком.
- **Чистый P/bang-bang** — отклонено опытным путём (прогоны 1–10): предельный
  цикл раскачивается лагом отклика ρ на параметры; охотничий поиск равновесия
  на репеллере не сходится.
- **Feedforward на ρ̇(ρ*)=0** — отклонено опытным путём (прогоны 11–12):
  зануляет производную в цели, но при ρ ниже цели динамика уводит вниз —
  клетка сидит на лезвии и сползает.
- **Модельно-предиктивный актюатор (принято)** — управление вычисляется
  из знания уравнения под скорость подхода при текущем ρ; хвостовая ошибка
  0.039 < ε=0.05, 100% хвоста в бюджете.

## Последствия

- Позитивные: контур замкнут; знание = вычисление из структуры; рой сходится
  без центральной карты; все приёмки зелёные (10 новых, старые не тронуты).
- Нейтральные: β остаётся внешней переменной (руль территории).
- Риски: модельный масштаб — метрики не операционализированы (закон 4
  «честные границы»); пороговой характер динамики сохраняется: при
  ρ > зона возврата (~0.5 при полном тормозе) runaway необратим.
