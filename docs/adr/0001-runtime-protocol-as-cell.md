# ADR-0001 · runtime-protocol как клетка роя

- **Статус:** принято
- **Дата:** 2026-11-07
- **Контекст:** мандат Хозяина TH-RTP-01/02 (картбланш: «интегрируй своё в репо», затем «одно другое не исключает — ты полимат=мультиагент»)

## Решение

1. Модель динамики узла живёт **отдельной клеткой** (отдельный репо
   `runtime-protocol`), а не папкой в ядре `cell-swarm` — по Закону 2 «Окно»
   (граница репо = граница контекста) и Закону 3 «Указатели» (геном хранит
   SHA, не контент).
2. Реализация — **stdlib-only Python**, метаболизм `make verify` / `make demo`,
   автономность clone→make→работает офлайн (Закон 1 «Клетка»).
3. Спецификация-источник фиксируется указателем на
   `rtynbirf/nous@agents/execution:docs/genesis/runtime-protocol.md`
   (коммиты TH-RTP-01: 85505f9, f483483f, 9bda88e5), не копируется.
4. В геноме `swarm.json` клетке присваивается префикс подсистемы
   `system_pre: "cognition"` — новый слой (когнитивный контур) наряду с
   substrate/metabolism/memory; обоснование: модуль моделирует динамику
   смысла узла, а не носитель, не обмен и не память.
5. Тесты (7 приёмок) и ADR добавляются в момент создания клетки (Закон 4
   «Храповик»): уравнение, дойное равновесие, инвариант ρ > 0, полный прогон
   до генезиса, волатильность мета-слоя, монотонность трейса, вердикты
   рак-фильтра.

## Альтернативы

- **Папка в cell-swarm** — отклонено: ядро = геном + фермент; тело клетки в
  ядре размывает границу контекста и инвертирует указатели.
- **Слияние в polymath-os** — отклонено: там ОС-субстрат, не модель; связка —
  пином, если/когда Хозяин решит.
- **Только документ в nous** — уже сделано (TH-RTP-01), но документ не
  исполняется; исполняемость требует клетки с метаболизмом.

## Последствия

- cell-swarm получает PR с одним изменением `swarm.json` (новая клетка + бамп
  genome_version 0.1.8 → 0.1.9) — по правилу ядра «правка состава клетки =
  правка генома с датой и методом получения SHA».
- Карта аккаунта (repo-doctrine 06) дополняется приложением о новом репо —
  по её же правилу 1 («каждое новое репо вносится в карту в день создания»).
- Операция фиксируется в ворклоге TH-RTP-02.
