# ADR-0006: Обратно-нить как свёртка журнала

- Статус: принято
- Дата: 2026-11-09
- Контекст: Волна ×4 · П50 (issue #3). Клетка несёт кровь (ADR-0004, конверты
  по событию) и reconciliation (ADR-0002/0003, сверку уровней). Ответ на урон —
  «обратно-нить» — до сих пор не имел формы: поведение, а не функция.
  Связано: cell-swarm#10 «Обратная нить как CI-гейт», общий канон свёртки —
  с пропагатором (task-graph-propagator).

## Проблема

Ответ на урон, размазанный по процедурам, нельзя ни replay-ить, ни сверить:
два прогона на одном журнале могут дать разные последствия, а состояние клетки
нельзя вывести из её истории. Нужна свёртка, а не сценарий.

## Решение

`fold.py` — обратно-нить = ЧИСТАЯ функция свёртки журнала событий:

1. **Общий канон свёртки** `fold_with(reducer, events, init)` — канон
   для пропагатора (task-graph-propagator) и клеток роя: редьюсер получает
   глубокие копии, чистота обеспечена механикой, не обещанием. `CANON_VERSION=1`.
2. **Обратно-нить** — частный редьюсер `fold_step`: strike (hp↓, debt[src]↑),
   heal (hp↑, cap), retaliate (списание нити долга). Только целые; канон долга:
   ноль = отсутствие записи.
3. **Обратимость** — инвариант `inverse(fold_step(s, e), e) == s` на каждом
   шаге; точность несёт аннотированный журнал (`annotate`: `prev_t`,
   `hp_before`, `had`) — свойство журнала, не глобальной памяти. Без аннотации
   обратный шаг отказывается (ValueError), не врёт «примерно».
4. **Приёмка** — property-тесты: replay журнала == состояние клетки
   (200 случайных журналов), двойной прогон свёртки идентичен байт в байт,
   чистота (журнал не мутируется), подмена события меняет состояние,
   монотонный счёт журнала обязателен.

## Следствия

- Журнал — единственный носитель правды: состояние клетки воспроизводимо
  из истории (replay), история не теряется при свёртке (обратимость).
- Контрольный прогон (`fold.py demo`) — witness канона в CI (`make verify`
  подхватывает `test_fold.py` автоматически).
- Кровь и свёртка согласованы: тот же канонический JSON (ADR-0004/0005),
  те же целые, tamper-evident остаётся за хеш-цепью крови.
