# Ротация крови-носителя (Actions-секрет CELL_SWARM_DISPATCH_TOKEN)

Токен — это кровь-носитель: по нему тела роя дотягиваются друг до друга
(repository_dispatch, допись летописи). Он НЕ часть генома и НЕ пин — он живой
секрет, и его смерть во время операции — штатная территория (случилось 2026-11-07:
коммит остался локальным, операция довязана по следу).

## Правило ротации (3 шага, каждый фиксирует факт)

1. **Минт** (только рука владельца, API этого не умеет из старого токена):
   GitHub → Settings → Developer settings → Fine-grained token (лучше классический
   с минимальным scope: `repo` на rtynbirf/*). Срок годности указывать всегда.
2. **Кровь в три тела** — с машины, где токен лежит в файле:
   ```bash
   python3 scripts/set_secret.py runtime-protocol cell-swarm polymath-os
   # факт: HTTP 204 (обновлён) или 201 (создан) на каждое тело
   ```
   Скрипт шифрует значение публичным ключом репо (sealed box) — токен не
   появляется в логах, переменных оболочки между шагами и в диффах.
3. **Пробный пульс** — dispatch клетки с новым носителем; факт = зелёный прогон
   blood.yml + допись эха в `cell-swarm/blood/LEDGER.jsonl`.

## Гигиена

- Токен, прошедший через чат или файл вне менеджера секретов, считается
  скомпрометированным: ротация при первой возможности, не «когда удобно».
- У воркфлоу `permissions: contents: read` — писать умеет только носитель-токен,
  не GITHUB_TOKEN. Так у крови один руль.
- Никогда не печатать токен, даже «первые символы»: длина и префикс — уже карта.
