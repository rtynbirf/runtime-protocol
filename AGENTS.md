# AGENTS.md — мембрана клетки runtime-protocol

Ты — агент, работающий в этой клетке роя. Пять законов роя действуют здесь
полностью (см. ядро `rtynbirf/cell-swarm`, README + docs/adr/).

## Порядок чтения

1. `MANIFEST.json` — ДНК клетки (роль, метаболизм, границы).
2. `runtime_protocol.py` — тело: уравнение, фазовая машина, фильтры.
3. `test_runtime_protocol.py` — живые приёмки (храповик: только добавляются).
4. `docs/adr/0001-runtime-protocol-as-cell.md` — почему клетка существует.

## Правила работы

1. **Геном — у ядра.** Состав и пины клеток меняются в `rtynbirf/cell-swarm`,
   `swarm.json`, с датой и методом получения SHA. Здесь геном не дублируется.
2. **Храповик.** Тесты и ADR только добавляются. Поведение, покрытое приёмкой,
   не меняется без новой приёмки, объясняющей смену.
3. **Честные границы.** Модельные метрики не выдавать за операционализированные.
   Любая попытка подать демо-масштаб как реальные данные — регресс мембраны.
4. **ρ > 0 — инвариант.** Код, допускающий ρ < 0 или «оживление» узла с ρ = 0,
   ломает аксиоматику и не принимается.
5. **Волатильный мета-слой.** Не реинтродуцируй `method_memory=True` после
   генезиса: откат неописуем по построению модели, а не запрещён дисциплиной.

## Грабли и золотая середина

Перед операциями прочти доктрину ошибок роя: `rtynbirf/repo-doctrine`,
файл `20-грабли-и-золотая-середина-агентов-2026-11-09.md` — 40 реальных событий
(Событие → Корень → Правило) и 10 законов золотой середины; чек-лист «10 касаний»
прогоняется перед каждым действием. Здесь родились главные грабли (№7–18 контур,
№19–23 критерии), поэтому особенно: 2–3 слепых прогона = СТОП, выводи закон из
модели, не крути четвёртую ручку (закон 1); копию контура снимать ДО мутации,
печать/проверка симметричны (закон 4); тест — честное свойство (реплей бит-в-бит),
не «вечный HOLD» (закон 8).

## Гигиена агента (Волна ×10, 2026-11-10)

Канон: repo-doctrine → `21-гигиена-уведомлений-и-красного-CI-2026-11-09.md`. Вход по закону: `github-runbook#10` (РЕЕСТР НЕДОДЕЛАННОГО · закон §5) + РЕЕСТР-КОСЯКОВ-ИИ + АНАТОМИЯ-КОСЯКОВ-ИИ (polimat-hub) — читать ДО первого действия.

1. Красный CI от твоего коммита — твой долг: живой зелёный прогон до конца сессии (rerun/диспатч/лат). Честный красный (внешний блок) — пломбой в github-runbook#10, не прятать.
2. Новые файлы — в манифесты тем же коммитом: SPDX/REUSE.toml, MANIFEST/portability.json, геном cell-swarm/swarm.json (пин следит за телом).
3. Не плодить уведомления: свой прогон доведи до зелёного; входящие треды разобрать и пометить прочитанными; UNREAD=0 — норма.
4. Пуш-гигиена: `pull --rebase` перед пушем; force-push запрещён; чужие волны и авто-коммиты (§3 реестра) не трогать; дубль снят честно = нет дубля.


## Никогда не делать (Never do)

- Never force-push в основную ветку: история роя append-only.
- Never трогать мембранные файлы (README.md, AGENTS.md, llms.txt) без пломбы в polimat-hub.
- Never коммитить секреты и токены: токен, попавший в чат, считается скомпрометированным и подлежит отзыву.
