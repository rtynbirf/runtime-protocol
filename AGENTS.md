# AGENTS.md — мембрана клетки runtime-protocol

Ты — агент, работающий в этой клетке роя. Пять законов роя действуют здесь
полностью (см. ядро `rtynbirf/cell-swarm`, README + docs/adr/).

## Порядок чтения

1. `MANIFEST.json` — ДНК клетки (роль, метаболизм, границы).
2. `runtime_protocol.py` — тело: уравнение, фазовая машина, фильтры.
3. `test_runtime_protocol.py` — живые приёмки (храповик: только добавляются).
4. `docs/adr/0001-runtime-protocol-as-cell.md` — почему клетка существует.

## Правила работы

1. **Геном — у ядра.** Состав и пины клеток меняются в `rtynbirf/cell-swarm`,
   `swarm.json`, с датой и методом получения SHA. Здесь геном не дублируется.
2. **Храповик.** Тесты и ADR только добавляются. Поведение, покрытое приёмкой,
   не меняется без новой приёмки, объясняющей смену.
3. **Честные границы.** Модельные метрики не выдавать за операционализированные.
   Любая попытка подать демо-масштаб как реальные данные — регресс мембраны.
4. **ρ > 0 — инвариант.** Код, допускающий ρ < 0 или «оживление» узла с ρ = 0,
   ломает аксиоматику и не принимается.
5. **Волатильный мета-слой.** Не реинтродуцируй `method_memory=True` после
   генезиса: откат неописуем по построению модели, а не запрещён дисциплиной.
